## 1. 当前审阅结论

该脚本已经修复最初审阅中几项最重要的前视偏差和时间对齐问题，目前可以作为结构较清晰的量化教学示例：

- 打分股票池不再根据未来标签是否存在进行筛选；
- rolling 因子使用完整历史预热，但截面去极值和标准化只使用当日 CSI300 成分股；
- 信号、成交和收益区间已经统一为 `T 日收盘生成信号 → T+1 开盘买入 → T+2 开盘退出/调仓`；
- 等权因子会根据训练期 IC 符号统一方向；
- 测试期末使用额外两个交易日结算，并显式计入最终清仓成本。

脚本语法和完整流程均已运行通过。最近一次验证中，测试信号截止于 2020-08-01，结算行情延长至 2020-08-04，362 个测试信号均生成了完整收益记录。

不过，当前回测仍使用“股票集合 + 简单平均收益”的教学性近似，没有真实维护持仓权重，也没有正确模拟停牌、涨跌停、成交失败、印花税和滑点。基准、模型选择和绩效指标也仍有明显改进空间。因此，当前结果可以用于学习和比较代码流程，但不宜直接作为投资或实盘结论。

## 3. 已修复的高优先级问题

### 3.1 打分股票池不再参考未来标签

当前代码第 337～363 行将数据明确拆为两种用途：

```python
scoring_df = processed.dropna(subset=FACTOR_COLS)
labeled_df = scoring_df.dropna(subset=["LABEL"])

train_df = segment(labeled_df, TRAIN_START, TRAIN_END)
valid_df = segment(scoring_df, VALID_START, VALID_END)
test_df  = segment(scoring_df, TEST_START, TEST_END)
```

含义是：

- 训练和 IC 检验需要同时具有因子和标签；
- valid、test 和实盘式打分只要求当时因子可用；
- valid/test 的标签只能在得分生成后用于事后评价，不能用来决定给哪些股票打分。

当前标签是 T+1 开盘至 T+2 开盘的未来收益。如果某只股票未来停牌、退市或缺少开盘价，`LABEL` 可能为空，但这不能成为 T 日提前排除该股票的理由。该问题已经修复；真正的无法成交仍应由交易模拟处理。

### 3.2 当日 CSI300 过滤已提前到截面预处理之前

当前代码第 317～335 行采用正确顺序：

```text
完整历史行情
→ 为每只股票计算 rolling 因子
→ 按日期过滤当日 CSI300 成分股
→ 在当日股票池内做 MAD 去极值和 Z-Score
```

保留入选前行情是为了给 rolling 窗口预热；但入选前或退出后的股票不能参与当日横截面均值、标准差、中位数和 MAD 的计算。当前实现已经把二者正确分开，避免未来成分股或已退出成分股污染历史截面。

### 3.3 信号、成交和标签时间已经统一

当前采用以下交易口径：

```text
T 日收盘：完整行情确定并生成信号
T+1 日开盘：买入或调仓
T+2 日开盘：卖出或再次调仓
```

标签位于当前代码第 279～281 行：

```python
LABEL = open_.shift(-2) / open_.shift(-1) - 1
```

即：

```text
LABEL[T] = open[T+2] / open[T+1] - 1
```

这个口径解决了“使用 T 日完整收盘数据后仍按 T 日收盘价成交”的时间矛盾，也满足普通 A 股当天买入后不能当天卖出的 T+1 交易限制。

当前实现仍假设可以按官方开盘价完成全部成交。停牌、涨跌停、集合竞价未完全成交、滑点和市场冲击仍未模拟，因此这是一个时间上自洽、但成交上理想化的教学口径。

### 3.4 等权合成已按训练期 IC 统一因子方向

当前代码第 425～440 行先根据训练期 IC 确定方向：

```python
train_ic = ic_table.loc[valid_factors, "IC均值"]
factor_directions = np.where(train_ic >= 0, 1.0, -1.0)
```

随后将同一组方向固定应用于 train、valid 和 test：

```python
score = mean(direction[factor] * factor_value[factor])
```

正 IC 因子保持不变，负 IC 因子乘以 `-1`，使校正后的所有因子都表达“数值越大，预期收益越高”。方向只使用训练期信息，不能根据验证期或测试期结果回头修改，否则会产生泄漏。

线性回归会自行学习系数正负，因此 LR 路径没有重复翻转输入因子。固定训练期方向仍隐含“方向在样本外保持稳定”的假设，后续可以考虑只使用历史信息的滚动 IC 或衰减 IC。

### 3.5 回测末端收益与成本已经显式对齐

当前代码第 123～176 行通过交易日历明确建立：

```text
信号日 T → T+1 开盘入场 → T+2 开盘退出/调仓
```

当前代码第 195～207 行还会自动寻找 `TEST_END` 之后的两个交易日。信号仍然只生成到 `TEST_END`，额外行情仅用于结算最后两个信号，不会产生新的测试信号。

如果数据源仍缺少 T+1 或 T+2，防御性检查会在扣成本前跳过该笔交易，避免出现“只有成本、没有收益”的孤立仓位。

回测末端采用最终清仓口径：最后一个收益区间在退出日开盘估值后，将剩余持仓卖成现金，并额外计入 `liquidation_turnover` 和清仓成本。因此当前净值表示扣除简化退出成本后的现金净值，而不是尚未退出的持仓市值。

## 4. 当前最重要的剩余问题：组合和交易模拟

### 4.1 等权收益与换手率口径仍不一致

当前代码第 141～154 行使用所选股票收益的简单平均：

```python
port_ret = period_rets.mean()
```

这相当于每次入场时所有股票都恢复为相同权重。可是换手率只根据股票集合变化计算：

```python
turnover = len(curr_set.symmetric_difference(prev_set)) / (2 * TOPK)
```

假设某只股票上涨后权重从 1/30 漂移到 1/20，即使它仍在下一期 Top30 中，也需要卖出一部分才能恢复等权；当前集合算法认为它“没有换出”，因此不会记录这部分交易量和成本。

标准做法应维护权重向量，并使用：

```text
换手率 = 0.5 × Σ|目标权重 - 调仓前漂移权重|
```

如果交易成本按买卖金额分别计算，则应直接计算买入金额和卖出金额，而不是只使用一个集合差异比例。

### 4.2 缺失收益仍会导致免费资金重分配

当前代码第 141～149 行：

```python
period_rets = (
    test_open_wide.loc[exit_date, valid_stocks]
    / test_open_wide.loc[entry_date, valid_stocks]
    - 1
).dropna()
port_ret = period_rets.mean()
```

如果一只目标股票停牌或缺少开盘价，代码会删除它，再对剩余股票重新求平均。这相当于把原本分给该股票的资金无成本分配给其他股票。

更合理的处理需要区分：

- 入场日无法买入：订单失败，相应资金保持现金；
- 已持仓但退出日停牌：持仓继续冻结，保留原权重并按明确规则估值；
- 数据质量问题：不能直接当成真实停牌，需要单独告警和修复。

### 4.3 交易成本模型仍过于简化

当前统一使用：

```python
TRANSACTION_COST = 0.001
net_ret = port_ret - turnover * TRANSACTION_COST
```

它没有区分：

- 买入佣金与卖出佣金；
- 卖出印花税；
- 最低佣金；
- 开盘滑点和市场冲击；
- 涨停无法买入、跌停无法卖出；
- 停牌和部分成交；
- 资金规模与成交量约束。

期末清仓成本目前也沿用同一统一费率。因此结果只能理解为理想化成本敏感性示例，不能当作真实 A 股交易成本。

### 4.4 股票数量不足时仍使用固定 `TOPK` 分母

换手率和期末清仓换手仍以 `TOPK` 为固定分母。如果某天候选股票不足 30 只，或部分股票无法成交，实际持仓数可能小于 `TOPK`，此时换手率会失真。

该问题与 4.1、4.2 本质相同：应以真实资金权重和现金余额为基础记账，而不是用股票只数近似资金变化。

## 5. 基准仍不严格

当前代码第 532～541 行虽然已经把基准收益区间统一为 T+1 开盘到 T+2 开盘，但基准股票池仍来自 `test_open_wide` 的全部列：

```python
benchmark_ret = (
    test_open_wide.loc[exit_date]
    / test_open_wide.loc[entry_date]
    - 1
).mean()
```

这些列是整个研究期间内曾经属于 CSI300 的股票合集，因此基准可能包含：

- 当时尚未进入 CSI300 的股票；
- 已经退出 CSI300 的股票；
- 因缺失值而每日动态改变权重的股票。

它既不是真实 CSI300 指数，也不是严格的当日 CSI300 成分股等权组合。策略还扣除了简化交易成本，而基准没有相同的调仓和成本过程，二者并非完全可比。

建议优先使用经过一致复权和时间对齐的真实 CSI300 指数 open-to-open 收益；如果希望构造等权基准，则必须使用每个日期的有效成分股、真实权重漂移、相同成交限制和相同成本规则。

## 6. 模型和研究流程问题

### 6.1 普通线性回归与选股目标不完全一致

当前代码第 463～479 行把所有“日期 × 股票”样本合并，使用普通线性回归优化个股未来 open-to-open 收益的均方误差，但策略最终关心的是每日截面排序和 Top-K 组合收益。

主要问题包括：

- 损失函数不是 Rank IC 或组合收益；
- 每日有效股票数不同，样本多的日期权重更高；
- `MOM_20D`、`MA_DEV` 等因子可能高度相关，OLS 系数不稳定；
- 标签极端值会明显影响均方误差；
- 没有正则化和时间序列交叉验证。

教学阶段可先改用 Ridge，并通过按时间切分的验证集选择正则化参数。标签也可以按日去均值、标准化或转换成截面 rank，使模型目标更接近选股目标。

### 6.2 验证集仍未真正驱动最终决策

当前代码第 482～502 行会展示 EW 和 LR 的 valid IC，这是正确的评价步骤；但脚本没有明确：

- 根据什么规则选择最终使用 EW 还是 LR；
- 是否使用 valid 选择 IC 阈值、TopK 或正则化参数；
- 选择方案后是否使用 train+valid 重新训练；
- 测试集结果是否只查看一次。

建议明确三区间职责：

```text
训练集：拟合参数并估计因子方向
验证集：选择因子、模型、阈值、TopK 和超参数
测试集：冻结所有规则后只进行一次最终评价
```

### 6.3 因子筛选仍有样本内乐观偏差

当前训练集同时用于计算 IC、按 `|IC| > 0.02` 筛选因子，以及展示筛选后组合的训练 IC。筛选后的训练结果天然偏高。

更可靠的判断应来自验证期或滚动样本外 IC，并补充：

- IC t 值；
- Rank IC 稳定性；
- 分组收益和多空收益；
- 因子相关性和冗余性；
- 分年度、分市场阶段表现。

### 6.4 ICIR 口径需要明确

当前 ICIR 定义为：

```text
IC 均值 / IC 标准差
```

这是未年化口径。部分研究平台会乘以 `sqrt(252)` 做年化，因此经验阈值不能在不同口径之间直接套用。脚本已经打印定义，但报告结果时仍应明确标注“未年化 ICIR”。

## 7. 绩效指标问题

相关代码：第 92～106 行。

### 7.1 夏普比率不是常用定义

当前使用：

```text
几何年化收益 / 年化波动率
```

更常见的日频夏普是：

```text
(日均收益 - 日均无风险收益) / 日收益标准差 × sqrt(252)
```

两种定义可能明显不同，应改用常见口径并注明是否扣除无风险收益。

### 7.2 最大回撤可能漏掉第一期亏损

当前净值直接从第一期收益后的值开始，没有在序列最前面补初始净值 1。如果第一期亏损，`cummax()` 会把亏损后的净值当成最初高点，从而漏掉从 1 到该净值的回撤。

应在净值序列前补一个初始值 1，再计算最大回撤。

### 7.3 缺少相对基准和成本分析指标

建议补充：

- 年化超额收益；
- 信息比率和跟踪误差；
- 相对最大回撤；
- 月度胜率；
- 毛收益、交易成本和净收益拆分；
- 分年度、分市场阶段表现。

## 8. 合理的教学简化，但需要明确披露

以下内容不属于直接程序错误，但会限制研究结论：

- 未进行行业和市值中性化，因子 IC 可能来自行业、规模或 Beta 暴露；
- Top30 纯多头组合没有行业上限、个股权重上限和风格约束；
- 测试期约 19 个月，覆盖的市场状态有限；
- `TURN_5D` 实际是成交量比，不是真正的换手率；
- `TURN_5D` 的五日均量包含当日成交量；若衡量异常放量，可与此前五日均量比较；
- 因子定义较基础，没有检验冗余性、相关性和分组单调性；
- `warnings.filterwarnings("ignore")` 可能掩盖 Pandas 行为变化和数据异常；
- 数据提供路径和输出目录仍依赖本地环境；
- 未记录 Python、Pandas、Qlib、数据版本和随机种子等实验环境信息。

## 9. 当前值得保留的设计

- train、valid、test 按时间顺序切分，没有随机打乱时间序列；
- rolling 因子使用完整历史预热，同时按当日成员区间构建截面；
- 打分集和有标签数据集已经分开管理；
- 信号、成交、收益和结算日期映射清晰；
- 等权方向只从训练集估计并冻结到样本外；
- 每日截面 MAD 去极值和 Z-Score 适合多因子选股教学；
- 同时展示等权与线性回归合成，有助于比较简单基线和统计模型；
- 输出信号日、入场日、退出日、换手、清仓换手和净收益，便于继续审计。

## 10. 后续建议实施顺序

### 已完成：消除主要前视偏差并统一时间口径

1. 分离打分数据和有标签数据。
2. 在截面预处理前过滤当日 CSI300 成分股。
3. 统一为 T 收盘信号、T+1 开盘入场、T+2 开盘退出/调仓。
4. 使用交易日历结算测试末端，并计入最终清仓成本。
5. 按训练期 IC 方向处理等权因子。

### 下一阶段：建立一致的组合会计

1. 使用“股票权重 + 现金权重”表示真实持仓。
2. 根据收益后的漂移权重计算下一次调仓量。
3. 对无法买入、无法卖出和停牌冻结分别建模。
4. 分离买入佣金、卖出佣金、印花税和滑点。
5. 修复缺失收益删除后免费再分配资金的问题。
6. 使用真实 CSI300 指数或严格构造的当日等权基准。

### 第三阶段：完善模型与验证

1. 使用验证集选择因子、模型、TopK 和正则化参数。
2. 使用 Ridge 或其他稳定模型替代裸 OLS 基线。
3. 增加滚动训练或 walk-forward 样本外检验。
4. 补充分组收益、Rank IC、IC t 值、因子相关性和稳定性分析。
5. 冻结研究方案后，测试集只评估一次。

### 第四阶段：完善绩效与复现

1. 统一夏普、最大回撤和超额指标定义。
2. 增加收益、风险和成本归因。
3. 保存配置、依赖版本、数据版本和运行时间。
4. 输出目标权重、实际成交、真实持仓、现金和成本明细。

## 11. 最终判断

当前版本已经完成原审阅“第一阶段”的主要任务：直接前视偏差、股票池截面污染、同收盘成交假设、因子方向和回测末端错配均已修复。它现在适合作为基本可信的量化流程教学示例。

但策略收益仍建立在理想化的组合和成交会计上。尤其是简单平均收益、集合换手率、缺失收益删除、统一成本率和非严格基准，可能显著影响收益、回撤和策略排名。因此，在完成权重向量、成交约束、真实成本和严格基准之前，当前年化收益与夏普比率仍不应被解释为可实现的投资绩效。
